Two gaps worth naming plainly

  1. Session expiry has no test. The refresh-and-retry path exists in auth_api.dart — a request that meets a 401 refreshes the token once and retries — but nothing forces an access token to actually expire and confirms the app recovers. §41 names "session expiration" as required testing.
    Why it slipped: proving it means forcing a token past its 15-minute life, which every other test today ran well inside.
  2. Invalid email has no backend test. DRF's EmailField does reject a malformed address — confirmed by hand — but no test in test_flows.py says so. The mobile app's local check is tested; the server's is not.
